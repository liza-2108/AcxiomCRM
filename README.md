# AcxiomCRM – Customer Relationship Management System

## Project Overview

AcxiomCRM is a web-based Customer Relationship Management system developed using Python Flask.

It helps organizations manage customers, leads, business opportunities, follow-ups, and user activities through a centralized platform.

## Features

- User Registration and Login
- Secure Password Hashing
- Account Lockout after 5 Failed Login Attempts
- Role-Based Access Control
- Customer Management
- Lead Management
- Opportunity Management
- Follow-up Management
- Dashboard with Charts
- Reports and Audit Logs
- REST API for Customers, Leads and Opportunities

## Technology Stack

| Technology | Purpose |
|---|---|
| Python | Backend Programming |
| Flask | Web Framework |
| SQLite | Database |
| Flask-SQLAlchemy | Database Management |
| HTML | Frontend |
| CSS | Styling |
| JavaScript | Frontend Functionality |
| Chart.js | Dashboard Charts |
